# Energy / Oil (WTI)

WTI is a random walk — ETS/ARIMA/naive identical to 4 decimals. Our agent
correctly finds nothing 92% of the time; false positives cost 4–7%.
**Lesson:** method is sound, task is impossible. Calibrate synthetic DGPs to
2–3pp effects.
