# data/m3mon/

M3 Monthly dataset (Monash Time Series Forecasting Archive).

- **Source:** https://zenodo.org/record/4656298 (`m3_monthly_dataset.zip`)
- **Origin:** M3 competition (Makridakis & Hibon, IJF 2000); 1428 monthly
  series across 6 domains, standard horizon h=18.
- **Used by:** exp61 (full ladder + proposed method): proposed 0.1476 beats
  equal weights 0.1641 (p=2.7e-44) and best single ets 0.1630 (p=3.5e-35).
  Third dataset confirming the proposed-method claim.
- **Note:** data files are gitignored; this README is force-added. Re-download
  from Zenodo to reproduce.
